\appendix
\chapter{Provenance of Figures and Quoted Numbers}
\label{app:provenance}

Every figure in this report is drawn by a script from files in \texttt{data/processed/}, which are themselves produced from raw downloads recorded in \texttt{data/raw/manifest.csv} with their URL, access date and SHA-256. The tables below list, for each figure, the processed files it is drawn from, the raw sources behind them and the code that produces them. Headline values quoted in the text are printed on the figures or appear in the chapter tables; the few numbers that appear only in prose (source-document figures such as EPRI's state total, and ratios derived from tabulated values) are listed with their sources in \texttt{docs/DATA\_NOTES.md}, which also records every data limit found during the audits. Rebuilding is one command per chapter (\texttt{make ch1}, \texttt{make ch2}, \texttt{make ch3}, \texttt{make ch4}); the standalone bundle reproduces every output byte for byte.
