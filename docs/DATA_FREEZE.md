# Data freeze: 2026-09-22

All figures, tables and numbers in the report are built from raw files recorded in `data/raw/manifest_frozen_2026-09-22.csv` (SHA-256 `622bc1fe6cf7227faa17a31ec0f4245efd199f4496c56411f28155ab8a39a1fc`), a copy of `data/raw/manifest.csv` restricted to access dates on or before 2026-09-22. It holds 643 rows for 640 source ids (7.49 GB); where a source was fetched more than once the pipeline uses the latest access date, as `src.ch1_baseline.manifest()` does. 0 of the 640 referenced files are missing from the local store.

**Rule.** Nothing fetched after the freeze date enters the report. The monthly snapshot job (`scripts/snapshot.py`) keeps adding ERCOT, CEC docket, PJM, Epoch and EIA-860M vintages under `data/snapshots/` and `data/raw/` for the longitudinal dataset, but a later vintage is used only in a new, dated freeze. The repository commit that carries this freeze is tagged `data-freeze-2026-09-22` (prepared at commit `961bc53`).
